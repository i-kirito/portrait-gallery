# 画廊魔法棒 · Qwen X 1.1.3

在 X 帖子静态图片左上角点击魔法棒，或在扩展弹窗选择多张本地图片一键提交，使用已保存的要求通过 WIND Qwen Q8 图生图，结果直接显示在原图位置并按需保存到 18889 画廊。只处理你点击或选择的图片，不读取推文指令、不自动发帖。

## 安装与连接

在画廊设置的 Chrome 扩展面板下载最新 ZIP。解压并在 chrome://extensions 加载已解压的扩展程序。已有版本只需更新原文件夹，在扩展页点重新加载，然后刷新 X。

连接地址、修改提示词和采样步数统一在画廊“设置 → Chrome 扩展”中管理。扩展打开后会按画廊保存的地址自动连接；无需输入密钥、密码或连接码。画廊在另一台电脑时，请先在画廊设置填写内网 IP（例如 192.168.31.216）。只申请你选择的地址的浏览器权限，不扫描内网。手动地址会保存，连接失败不改连其他服务器。为兼容任意内网 IP，扩展声明了网页消息入口，但后台只接受当前配置的本机/内网画廊地址，并拒绝公网来源；普通网页不能借此访问画廊接口。

扩展内部自动建立仅能使用 Qwen 图生图接口的连接，不获取画廊管理员权限。自动连接只供本机/可信内网使用，不面向公网；普通网页来源拒绝。画廊登录验证不受影响。可以在扩展中断开，或在画廊设置停用所有扩展连接。

## 使用

保存修改提示词后刷新 X，在图片左上角点击魔法棒。改图完成后会直接叠加在原图位置，再点魔法棒可在原图与改后图之间切换；改后图右上角提供“放大查看”和“保存到画廊”，右下角的“↻”按钮可沿用当前提示词重新生成，旧结果会保留在任务记录中；默认不写入画廊，点击“保存到画廊”才会保存。扩展里的最近任务按钮会回到对应 X 原帖，不再默认打开扩展结果页。只在用户点击时提交生成，超时不自动重复提交或改用其他模型。扩展保存最近任务，同一画廊重新连接保留任务；切换画廊时分别保留各自任务记录。

画廊“设置 → Chrome 扩展”与扩展弹窗都支持“批量上传改图”和“最近任务”。可选择任意数量的 JPEG、PNG 或 WEBP（每张不超过 10 MiB），点击“一键改图”后会逐张提交；失败项会显示文件名和原因。上传任务可从扩展“最近任务”打开结果页，默认不保存到画廊，确认后再点击“保存到画廊”。最近任务支持单项删除和一键清空，清理的是扩展本地任务记录，不会删除已保存到画廊的图片。

原图保留，结果页可前后对比。Qwen、WIND 和画廊需要在线。本机地址指当前运行 Chrome 的电脑；其他电脑需手填画廊所在设备的 IP。

权限只包含存储、任务闹钟、X 内容脚本及本机/指定画廊地址。其他地址权限在手动连接时逐个申请，不读取 X Cookie、私信或密码。安装包不包含用户密码、私钥或已登录会话。
